## Getting the answers into the hunt

1. In Microsoft Forms, open **Responses → Open in Excel**.
2. Select the whole sheet including the header row, and copy.
3. Admin → Treasure hunt → **7 · Know your colleagues** → paste into **Paste the form results** → **Fill in answers** → check the wrong options → **Save answers**.

If someone submits twice, the later row wins.
