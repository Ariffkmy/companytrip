Atami Treasure Hunt · Game Master pack

For Ariff only.

Answer key, setup and score sheet for running the hunt on WhatsApp if the app is down. Don’t share this with the groups.

CONFIDENTIAL · CONTAINS ANSWERS

Before the day (while the app still works)

  • Fill in your WhatsApp number on page 1 of the players’ manual, then print it or share the PDF with all four leaders.
  • Create four WhatsApp groups: “Find the boss – Group A/B/C/D”, each with that group’s members, Tim, Ellice and you.
  • Save every group’s reference photos to your phone, by group: bingo tiles (numbered), Copy the pose WHERE + POSE (+ Maps link), Atami quiz landmark WHERE photo. They are in Admin → Hunt editor.
  • Export the Know your colleagues questions and answers for each group (they live in the database, so you can’t get them once the server is down). Print or save them.
  • Check the Look around you questions in the editor match the manual; reprint if they were edited.
  • Tell Tim and Ellice: in offline mode they answer yes/no in each group’s chat, post “🚶 We’re moving” in all four chats when they move, and WhatsApp you each pitch rating (group + 1–10).

Switching to offline mode

  1. Post in the trip group: “Treasure hunt is now OFFLINE. Leaders, open the offline manual.”
  2. Send each leader their group’s reference photos (bingo card, pose, landmark).
  3. Send START (or, mid-hunt, tell everyone how many minutes are left). Note the time: ______
  4. Write down the stamps each group already had in the app, if you can still see them.

While it runs

  • Reply ✅ Stamp N as soon as you accept a game. Log it on the score sheet with the WhatsApp time.
  • Bingo: stamp only when every tile has a correct selfie. 1 point per tile.
  • Atami quiz: call the leader, read 15 questions from the bank (skip ones they’ve already had), 10 seconds each. A time-out restarts from question 1 with new questions. Pass = 10 right. Points = 2 × right in the passing round.
  • Buy it, try it: stamp needs the video and the bosses’ rating. Points = 2 × rating.
  • Look around you: first message only. Mark at the finish.
  • Know your colleagues: call the leader, ask all questions, no pass mark. Points = 2 × right.
  • Find the boss: 20 for the photo with both bosses. 2 questions per group per spot.
  • Several groups ready for a call? Take them in the order their “Ready” messages arrived. Carmen or Kevin can run a quiz call with this pack.
